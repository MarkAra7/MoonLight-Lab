# MoonLight Lab — Frontend

React + Vite + Tailwind CSS v4 + Flowbite React frontend for the MoonLight Lab
quiz and learning platform. Consumes the Laravel 11 API in `../backend`.

## Stack

| Layer        | Choice                                       |
| ------------ | -------------------------------------------- |
| Framework    | React 19                                     |
| Build tool   | Vite 8 (with `@tailwindcss/vite` plugin)     |
| Styling      | Tailwind CSS v4 (CSS-first config)           |
| UI library   | Flowbite React 0.12                          |
| Theming      | Moonlight theme (light + dark toggle)        |
| Routing      | React Router 7 (BrowserRouter)               |
| HTTP client  | Axios (Sanctum bearer-token interceptor)     |
| Linting      | ESLint flat config (react-hooks, refresh)    |

## Getting started

```bash
# 1. Install dependencies
npm install

# 2. Copy environment template (optional)
cp .env.example .env

# 3. Run the Laravel API (backend/) on a separate terminal, e.g.:
#    cd ../backend && php artisan serve

# 4. Start the dev server (proxies /api and /storage to localhost:8000)
npm run dev

# Production build
npm run build

# Lint
npm run lint
```

## Theming

- Light/dark mode is toggled with the navbar `ThemeToggle`
  (`src/components/ThemeToggle.jsx`).
- The choice persists in localStorage under `theme`
  (`light` | `dark` | `auto`), applied before first paint by an inline script
  in `index.html` to avoid a flash.
- Dark styling uses class-based variants: `@custom-variant dark` in
  `src/index.css` activates Flowbite `dark:` classes when `.dark` is on
  `<html>`.
- Component-level Flowbite overrides live in `src/theme/moonlightTheme.js`
  (passed to `<ThemeProvider theme={moonlightTheme}>` in `src/main.jsx`).

## Configuration

- `vite.config.js` — dev port `5173`, `@` → `src` alias, API/storage proxy to
  the Laravel backend (`http://localhost:8000`), plus the Flowbite React and
  Tailwind Vite plugins.
- `.env` — optional overrides via `VITE_API_BASE_URL` and `VITE_STORAGE_BASE_URL`.
- `.flowbite-react/` — generated by `flowbite-react/plugin/vite` on every build
  and dev run (component class list + theme init). Git-ignored; do not edit.

## API conventions

The Laravel API is mounted under `/api/v1`. The Axios client attaches the
Sanctum token from `localStorage` (`mlab_token`) to every request and clears
it on `401`. Endpoint modules in `src/api/` mirror the backend routes defined
in `../backend/routes/api.php`.

## Adding a new page

1. Create the page component under `src/pages/<feature>/`.
2. Register it in `src/router/routes.jsx`.
3. Add any backing HTTP calls to the matching module in `src/api/`.
